# ESP32-C3 Console

Карманная мини-консоль на **ESP32-C3** с OLED-дисплеем и джойстиком. Внутри три игры и «шпаргалки» — короткие текстовые заметки, которые отправляются на устройство по Bluetooth LE и хранятся в энергонезависимой памяти.

## Возможности

- 🎮 **Brick Out** — арканоид: 10×5 кирпичей, 3 жизни, подсчёт очков
- 🐍 **Snake** — змейка на поле 32×16, скорость растёт вместе со счётом
- 🏓 **Pong** — игра против ИИ до 5 очков
- 📝 **Cheats** — до 64 строк по 40 символов, управление по BLE (Nordic UART Service)
- 💾 Строки сохраняются в NVS (`Preferences`) и переживают перезагрузку
- 📶 Индикатор подключения BLE в меню и в разделе Cheats

## Железо

| Компонент | Описание |
|---|---|
| Плата | ESP32-C3 |
| Дисплей | OLED SSD1306, 128×64, I²C, адрес `0x3C` |
| Управление | Аналоговый джойстик с кнопкой |

### Подключение

| Сигнал | GPIO |
|---|---|
| OLED SDA | 4 |
| OLED SCL | 5 |
| Джойстик VRx | 1 |
| Джойстик VRy | 0 |
| Джойстик SW | 10 (внутренняя подтяжка `INPUT_PULLUP`) |
| Источник случайности | 2 (не подключать, `randomSeed(analogRead(2))`) |

## Сборка и прошивка

### Библиотеки

Установите через Library Manager в Arduino IDE:

- `Adafruit GFX Library`
- `Adafruit SSD1306`

`Wire`, `Preferences` и `BLE*` входят в состав ядра ESP32.

### Шаги

1. Установите в Arduino IDE ядро **esp32 by Espressif Systems** (Boards Manager).
2. Выберите плату **ESP32C3 Dev Module**.
3. Если используете USB напрямую, включите **USB CDC On Boot: Enabled**.
4. Откройте `esp32_console.ino` и загрузите скетч на плату.

> Папка со скетчем должна называться так же, как и `.ino`-файл (`esp32_console`), иначе Arduino IDE предложит создать новую.

## Калибровка джойстика

Центр джойстика задан константами в начале скетча:

```cpp
int16_t joyCX = 2230;
int16_t joyCY = 2185;
```

У разных джойстиков нейтральное положение отличается. Выведите в Serial значения `analogRead` для осей в покое и подставьте свои числа.

## Управление

| Экран | Действие |
|---|---|
| **Меню** | Стик вверх/вниз — выбор, нажатие SW — открыть |
| **Brick Out** | Стик влево/вправо — ракетка, SW или стик вверх — запуск мяча |
| **Snake** | Стик в любую сторону — поворот |
| **Pong** | Стик вверх/вниз — ракетка |
| **Cheats** | Стик вверх/вниз — прокрутка, SW — назад |
| **Game Over** | SW — в меню, стик вверх — рестарт |
| **About** | SW — назад |

## Cheats по Bluetooth LE

После включения устройство рекламируется под именем **`ESP32-CHEATS`** и поднимает сервис, совместимый с Nordic UART Service:

| Характеристика | UUID | Свойства |
|---|---|---|
| Service | `6E400001-B5A3-F393-E0A9-E50E24DCCA9E` | — |
| RX (запись на устройство) | `6E400002-B5A3-F393-E0A9-E50E24DCCA9E` | Write, Write No Response |
| TX (ответы устройства) | `6E400003-B5A3-F393-E0A9-E50E24DCCA9E` | Notify |

### Команды

Каждая команда завершается символом новой строки (`\n` или `\r`).

| Отправка | Результат |
|---|---|
| `любой текст` | Добавляется новая строка в шпаргалки |
| `LIST` | Устройство отвечает уведомлением: `Lines: N` и все строки |
| `CLEAR` | Удаляет все сохранённые строки |

### Как подключиться

1. Установите BLE-терминал, например **nRF Connect**, **LightBlue** или **Serial Bluetooth Terminal** (режим BLE).
2. Найдите устройство `ESP32-CHEATS` и подключитесь.
3. Включите Notify на TX-характеристике, чтобы получать ответ на `LIST`.
4. Отправляйте строки в RX-характеристику — не забывайте про перевод строки в конце.
5. На устройстве откройте пункт **CHEATS**.

### Ограничения

- Максимум **64 строки**, максимум **40 символов** в строке (лишнее обрезается).
- Встроенный шрифт Adafruit GFX поддерживает только ASCII — кириллица на дисплее не отображается. Используйте латиницу или транслит.
- Ответ на `LIST` отправляется одним уведомлением, поэтому при большом числе строк он может обрезаться из-за размера MTU.
- На экране помещается 6 строк одновременно.

## Как устроен код

Программа построена как простой конечный автомат: `ST_MENU`, `ST_BRICK`, `ST_SNAKE`, `ST_PONG`, `ST_CHEATS`, `ST_ABOUT`. Для каждого состояния есть своя функция `*Loop()`, которую вызывает `loop()`. Ввод с джойстика обрабатывается функциями `swPressed()`, `stickUp()` и `stickDown()` с программным антидребезгом (200 мс).
